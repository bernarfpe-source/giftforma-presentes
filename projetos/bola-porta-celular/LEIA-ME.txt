BOLA PORTA-CELULAR + PORTA-CANETAS  (brinde Rio Novo / FMT) -- modelado com text-to-cad

ARQUIVOS
- src/bola.py ............ o modelo (build123d / text-to-cad). Medidas ajustaveis no topo (model.param).
- logos/rio-novo.png ..... logo oficial; o script separa azul e verde e vetoriza sozinho.
- STEP/ .................. CAD exato (abre no Fusion, SolidWorks, FreeCAD).
- 3MF/ ................... para o fatiador (Bambu Studio / Orca): um objeto por cor, ja colorido.

RODAR (Windows PowerShell ou Linux)
  irm https://www.texttocad.dev/install.ps1 | iex      (instala o cad, uma vez)
  cad server start
  cad run src/bola.py                                   (abre/atualiza o visualizador)
  cad model export <id> STEP/bola_porta_celular.step 3MF/bola_porta_celular.3mf
  cad model dfm <id> --process printing --technology fdm --material pla

CHECAGEM DE IMPRESSAO (FDM, PLA): OK, 0 erros. Avisos restantes = encostos entre cores
(normais em peca multicor) e pontas dos pentagonos cortados pela face/topo.

PENDENCIAS: logo oficial da FMT (+ autorizacao), prototipo impresso.
